<threat_model>
- T5-ORIGIN: an external page or subresource reaches the project bridge. Use one
  reserved private HTTPS origin, block all off-origin packaged-browser navigation
  and resource loads, and attach the bridge only to this packaged mode.
- T5-PATH: encoded separators, traversal, query tricks, or absolute paths escape
  `/webui/`. Parse and validate the raw URI, reject ambiguous encodings and dot
  segments, and map only normalized relative bundle paths through classpath lookup.
- T5-CONTENT: MIME confusion or permissive browser defaults execute unexpected
  content. Allow only required methods and known bundle content types; add CSP,
  `nosniff`, no-referrer, no-form, no-frame, and no-store policies.
- T5-LIFECYCLE: handlers outlive the browser/project or are installed after the
  first request. Register before `loadURL`, unregister during idempotent browser
  disposal, and continue disposing bridge before browser.
- T5-REGRESSION: fakes, archive presence, or Plugin Verifier pass while Chromium
  still shows an error page. Require fresh signed-product visual UAT on both exact
  host versions after all automated gates pass.
</threat_model>
