<threat_model>
## Trust Boundaries
| Boundary | Description |
|---|---|
| Tool-window factory → discovery graph | A missing or ambient dependency could bypass the enforced read-only graph. |
| Browser store → JCEF bridge | Section, filter, cancellation, and navigation requests can be stale, forged, or misrouted. |
| Content/project disposal → background/JCEF state | Late work or callbacks can retain IDE/browser authority after close. |

| T2-WIRE-18 | Elevation of privilege | composition root | mitigate | Constructor-only deny-effect graph, no service lookup, full forbidden reachability scan. |
| T2-STALE-18 | Spoofing | store/bridge routing | mitigate | Request-token and snapshot-revision checks; late responses discarded. |
| T2-LEAK-18 | Denial of service | disposal | mitigate | Ordered cancel/join/clear/handler/browser disposal plus exact-host weak-reference probes. |
| T2-MUTATE-18 | Tampering | installed lifecycle | mitigate | Full open/browse/navigate/cancel/close mutation tripwire and packaged ZIP scan. |
